# Інструкція запуску

Скрипт приймає технічне питання, шукає в DuckDuckGo, читає знайдені сторінки й просить безкоштовну модель Gemini скласти структуровану відповідь (коротка відповідь, таблиця/кроки, ризики) лише за цими джерелами. Результат зберігається в `evidence/results/`, кожен запуск пишеться в `evidence/runs_log.csv`.

## Запуск

1. Необхідно Отримати безкоштовний ключ у [Google AI Studio](https://aistudio.google.com/apikey) (кнопка *Create API key*). Оплата не потрібна.
2. Встановити залежності й задати ключ:

```bash
cd mkr1/solution
pip install -r requirements.txt
export GEMINI_API_KEY="ваш_ключ"      
```

3. Запуск:

```bash
python research.py ask "Prisma vs Drizzle for Next.js" --manual-min 20
python research.py verify 1 ok --check-min 3
python research.py stats
```

Потрібен Python 3.10+. Ключ не додавайте в репозиторій.

## Команди

| Команда | Що робить |
|---|---|
| `ask "питання" [--manual-min N]` | Шукає, формує `evidence/results/NNN-....md`, дописує рядок у лог. `--manual-min` — скільки хвилин зайняло б вручну |
| `verify ID ok\|bad [--check-min N]` | Позначає, чи джерела підтвердили відповідь, і скільки хвилин пішло на перевірку |
| `stats` | Середній час, токени, частка підтверджених відповідей |

## Налаштування (необов`язково)

- `MODEL` — ID моделі Gemini з безкоштовним рівнем (за замовчуванням `gemini-3.8-flash`). 
- `MAX_RESULTS` (6), `FETCH_TOP` (4), `PAGE_CHARS` (4000) — скільки результатів брати, скільки сторінок читати повністю і скільки тексту з кожної.

## Поради

- Для технічних питань пошук англійською зазвичай дає кращі джерела.
- Якщо пошук тимчасово не працює (DuckDuckGo може обмежувати часті запити), треба зачекати хвилину й повторити.
- Безкоштовний рівень має ліміти запитів на хвилину/день: при 429 скрипт сам чекає 30 с і пробує ще раз.
